# AutoRigForHumanoid For Maya

VRChat用アバターなどのUnity共通規格（Humanoid）に沿って作成された3Dモデルを読み込み、
クリーンアップからピッカー付きリグの作成までを数クリックで行うツール。

## 機能一覧

- **FBX の入出力** — FBXの読み込み、Unity向けの出力、FBXASCの文字化けの修正
- **リグの自動作成** — 読み込んだキャラクターをアニメーション作成用にセットアップ
- **ブレンドシェイプ用コントローラー** — ブレンドシェイプを操作するコントローラーの作成
- **ピッカー** — 別の Maya ファイルのリグを、Pickerが使える状態でシーンへ読み込み
- **別ファイルのリグの読み込み** — 別の Maya ファイルのリグを、Pickerが使える状態でシーンへ読み込み

## 動作環境

- Autodesk Maya 2025 以降
- Windows

## インストールと起動

1. Codeをscriptsフォルダに配置

2. Maya のスクリプトエディター(Python タブ)で次を実行。ウィンドウが開く。

   ```python
   from フォルダ名 import show_window
   show_window()
   ```

## リグの作り方

アクセサリの **Import FBX** からモデルを読み込み、**Freeze Scale** でスケールを適用。ウィンドウの **リグ制作** タブから作成。

### 1. Jointを割り当てる(初期設定)

1. **キャラクター名** の入力。
2. 各欄へのキャラクターのジョイントの入力。
   - **自動割り当て**: ジョイント名から推測しての自動入力
   - **割り当て**: 選択中のJointを入力
   - **選択**: 欄のジョイントをシーンで選択

### 2. ガイドの作成

1. **主軸**(スキンのJointの子の方向)の選択。
2. **ガイド作成** をクリック。
3. ガイドを動かして、回転・移動を調整。

### 3. リグを作る

**リグ作成** をクリックすると、コントローラー一式が作成される。

### 4. ポーズを付ける

ウィンドウ上部の **Picker表示** で Picker を表示。

| ボタン | できること |
|---|---|
| 図の各ボタン | そのコントローラーの選択(Shift を押しながらで追加選択) |
| All Finger | 指のコントローラーの一括選択 |
| Select ALL | すべてのコントローラーの選択 |
| Reset Pose | すべてのコントローラーの初期状態への復帰 |
| Mirror Pose | 現在のポーズの左右反転 |
| IK>>FK / FK>>IK | 腕・脚の FK/IK の、見た目のポーズを保ったままの切り替え |
| ArmVis / LegVis / HandVis など | 部位ごとのコントローラーの表示・非表示の切り替え |
| Flat Shade | ビューポートのフラット表示 |

- 作成直後の状態は **腕が FK、脚が IK**。

### シェイプの保存、読み込み

コントローラーの形を手直ししたあとのリグの作り直しには、**リグ制作** タブの **コントロールシェイプ** を使用。

1. 作り直す前に **Export Shape** で形を保存。
2. リグの作り直し。
3. **Import Shape** で保存した形を読み込むと、同じ名前のコントローラーへ形が復元される。

コントローラーを選択している場合は、選択したものだけが対象。何も選択していない場合は、すべてが対象。

## ブレンドシェイプ用コントローラー

**ブレンドシェイプ** タブでの、表情などのブレンドシェイプを操作するコントローラーの作成。

1. **オブジェクト** への顔などのメッシュの割り当て。**シェイプ**・**スキンクラスター**・**ブレンドシェイプ** は「自動割り当て」で入力。
2. **適用** をクリック。
3. 作りたいコントローラーの種類を開き、名前・色・対応するブレンドシェイプを選んで **作成** をクリック。

| 種類 | 動かし方 |
|---|---|
| 1*1 | 1 方向の移動で 1 つのブレンドシェイプを操作 |
| 2*1 | 1 方向の移動で、プラス側・マイナス側の 2 つを操作 |
| 1*2 | 縦横 2 方向の移動で、それぞれ 1 つずつを操作 |
| 2*2 | 縦横 2 方向の移動で、それぞれプラス・マイナスの計 4 つを操作 |

## アクセサリ

**アクセサリ** タブに、補助的な機能を集約。

### リグ読み込み

別の Maya ファイルで作ったリグの、いまのシーンへの読み込み。読み込んだリグも、そのまま Picker で操作可能。

1. **Maya Scene** への読み込みたいファイルの指定(**参照** で選択可能)。
2. **Import Rig** をクリック。

- このツールで作ったリグの読み込み専用。
- 古い版で作ったリグは、読み込めても Picker が使えない場合がある。その場合はリグの作り直し。

### 複数のキャラクターを 1 つのシーンで使う

別ファイルのリグの読み込みによる、1 つのシーンへの複数キャラクターの配置。Picker の操作対象は、`ARFH_information` ノードの `characterName` へのキャラクター名の入力で切り替え。

### FBX

**FBX** サブタブの 3 つの機能。

**FBXインポート**
- **Import FBX**: FBX ファイルのシーンへの読み込み
- **Freeze Scale**: 読み込んだキャラクターのスケールが 1 でなく、メッシュが痩せたり崩れたりする場合の修正。ジョイントのルートを選んでクリック

**Unity FBX 書き出し**
**FBX Exporter For Unity** のクリックで、アニメーション付き FBX を Unity 向けに書き出す画面を表示。作業中のシーンには手を加えず、確認付きで書き出し。

1. ジオメトリとスキンの全ジョイントを含む親グループの選択。
2. **Use selection** での対象の指定と、開始・終了フレームの確認。
3. **Export and verify on a copy** をクリックし、新しい FBX ファイル名を指定(既存のファイルは上書きされない)。

書き出しの開始で「書き出し状況」画面を表示。複数の書き出しの同時進行が可能で、完了・失敗は一覧に残る。**書き出し状況を表示** ボタンで再表示。確認に失敗した場合は FBX を出力せず、原因を記録。

**FBX名の整形**
FBX 内のブレンドシェイプ名(日本語名など)を別の名前に置き換えた FBX の作成。Maya のシーンは変更なし。

1. **変換元 FBX** の **参照** でファイルを選択(Json と変換後 FBX のパスは自動入力)。
2. **Json出力** で、元の名前と変換後の名前の対応表を作成。
3. 対応表を開いての、変換後の名前の編集(変換後の名前が重複するとエラー)。
4. **モード** を選んで **FBX出力** をクリック。
   - `Kay To Value`: 元の名前 → 変換後の名前
   - `Value To Kay`: 変換後の名前 → 元の名前(元に戻す)

## ウィンドウの見方

ウィンドウ上部に **Picker** ボタンを常時表示。その下がタブ構成。

| 場所 | 内容 |
|---|---|
| Picker(常時表示) | ポーズ操作用の Picker の表示 |
| リグ制作 | 初期設定 → ガイド作成 → リグ作成 → コントロールシェイプ |
| アクセサリ | リグ読み込み、FBX(インポート・Unity 書き出し・名前の整形) |
| ブレンドシェイプ | ブレンドシェイプ用コントローラーの作成 |

## 制限事項

- 一般的なHumanoid構造にのみ対応 四足歩行や多腕には非対応。
- 既にリグが存在するシーンでリグの作成は不可。別シーンで作成してから読み込むこと。
