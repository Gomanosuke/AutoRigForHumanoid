# AutoRigForHumanoid For Maya

VRChat 用アバターのように、Unity の Humanoid 規格に沿って作られた3Dモデルに、アニメーション用のリグを自動で組む Maya ツールです。FBX の読み込みと下準備から、ピッカー付きのリグの作成、Unity 向けの書き出しまでを1つのウィンドウで行えます。

## 主な機能

- **リグの自動作成**: ジョイントを割り当ててガイドを調整すると、コントローラー一式を作ります。
- **ピッカー**: コントローラーをボタンで選択し、ポーズのリセット・左右反転・IK/FK の切り替えができます。
- **ブレンドシェイプ用コントローラー**: 表情などのブレンドシェイプを動かすコントローラーを作ります。
- **別ファイルのリグの読み込み**: ほかの Maya ファイルで作ったリグを、ピッカーが使える状態でシーンに読み込みます。
- **FBX の入出力**: FBX の読み込みと、アニメーション付き FBX の Unity 向け書き出しができます。FBX 内のブレンドシェイプ名の置き換えにも対応しています。

## 動作環境

- Autodesk Maya 2025 以降
- Windows

## インストールと起動

1. Maya の `scripts` フォルダー（通常は `Documents/maya/scripts`）に、このリポジトリを `AutoRigForHumanoid` という名前のフォルダーで置きます。

   ```bash
   git clone https://github.com/Gomanosuke/AutoRigForHumanoid.git
   ```

2. Maya のスクリプトエディターの Python タブで次を実行すると、ウィンドウが開きます。

   ```python
   from AutoRigForHumanoid import show_window
   show_window()
   ```

## ウィンドウの構成

ウィンドウの上部には **Picker表示** ボタンが常にあり、その下が3つのタブに分かれています。

| 場所 | 内容 |
|---|---|
| Picker（上部） | ポーズを付けるためのピッカーを開く |
| リグ制作 | 初期設定 → ガイド作成 → リグ作成、コントロールシェイプの保存と読み込み |
| アクセサリ | 別ファイルのリグの読み込み、FBX（読み込み・Unity 向け書き出し・名前の変換） |
| ブレンドシェイプ | ブレンドシェイプ用コントローラーの作成 |

## リグを作る

まず **アクセサリ** タブの **FBX** から **Import FBX** でモデルを読み込みます。スケールが1になっていないモデルは、ジョイントのルートを選んで **Freeze Scale** を押してください。そのままリグを作ると、メッシュが痩せたり崩れたりすることがあります。

準備ができたら、**リグ制作** タブで次の順に進めます。

### 1. ジョイントを割り当てる

1. **キャラクター名** を入力します。
2. 各欄に、キャラクターの対応するジョイントを入力します。各欄の横のボタンは次のように使います。
   - **自動割り当て**: ジョイント名から推測して、すべての欄を埋めます。
   - **割り当て**: シーンで選択しているジョイントを、その欄に入れます。
   - **選択**: その欄に入っているジョイントを、シーンで選択します。

### 2. ガイドを作る

1. **主軸** を選びます。スキンのジョイントで、子ジョイントがある方向の軸です。
2. **ガイド作成** を押します。
3. 表示されたガイドを動かして、関節の位置と向きを調整します。

### 3. リグを作る

**リグ作成** を押すと、コントローラー一式ができます。作成直後は、腕が FK、脚が IK になっています。

### 4. ポーズを付ける

ウィンドウ上部の **Picker表示** でピッカーを開きます。

| ボタン | 動作 |
|---|---|
| 図の各ボタン | そのコントローラーを選択（Shift を押しながらで追加選択） |
| All Finger | 指のコントローラーをまとめて選択 |
| Select ALL | すべてのコントローラーを選択 |
| Reset Pose | すべてのコントローラーを初期状態に戻す |
| Mirror Pose | 今のポーズを左右反転 |
| IK>>FK / FK>>IK | 腕・脚の FK と IK を、見た目のポーズを保ったまま切り替え |
| ArmVis / LegVis / HandVis など | 部位ごとにコントローラーの表示・非表示を切り替え |
| Flat Shade | ビューポートをフラット表示に切り替え |

### コントローラーの形を保存する

コントローラーの形を手直ししたあとでリグを作り直すときは、**リグ制作** タブの **コントロールシェイプ** で形を保存しておけます。

1. 作り直す前に **Export Shape** で形を保存します。
2. リグを作り直します。
3. **Import Shape** で保存した形を読み込むと、同じ名前のコントローラーに形が戻ります。

コントローラーを選択していれば、選択したものだけが対象になります。何も選択していなければ、すべてのコントローラーが対象です。

## ブレンドシェイプ用コントローラーを作る

**ブレンドシェイプ** タブでは、表情などのブレンドシェイプを動かすコントローラーを作れます。

1. **オブジェクト** に顔などのメッシュを割り当てます。**シェイプ**・**スキンクラスター**・**ブレンドシェイプ** は **自動割り当て** で入力できます。
2. **適用** を押します。
3. 作りたい種類のコントローラーの欄を開き、名前・色・対応するブレンドシェイプを選んで **作成** を押します。

| 種類 | 動かし方 |
|---|---|
| 1*1 | 1方向の移動で、1つのブレンドシェイプを動かす |
| 2*1 | 1方向の移動で、プラス側とマイナス側の2つを動かす |
| 1*2 | 縦と横の移動で、それぞれ1つずつを動かす |
| 2*2 | 縦と横の移動で、それぞれプラス側とマイナス側の計4つを動かす |

## アクセサリ

**アクセサリ** タブには、リグ作成を補助する機能をまとめています。

### 別ファイルのリグを読み込む

ほかの Maya ファイルで作ったリグを、今のシーンに読み込みます。読み込んだリグもピッカーで操作できます。

1. **Maya Scene** に読み込むファイルを指定します（**参照** から選べます）。
2. **Import Rig** を押します。

読み込めるのは、このツールで作ったリグだけです。古いバージョンで作ったリグは、読み込めてもピッカーが使えないことがあります。その場合はリグを作り直してください。

1つのシーンに複数のキャラクターを置きたいときも、この機能を使います。ピッカーで操作するキャラクターは、`ARFH_information` ノードの `characterName` にキャラクター名を入力して切り替えます。

### FBX を読み込む

**FBX** サブタブの **FBXインポート** 欄にあります。

- **Import FBX**: FBX ファイルをシーンに読み込みます。
- **Freeze Scale**: スケールが1になっていないキャラクターを修正します。ジョイントのルートを選んでから押してください。

### Unity 向けに FBX を書き出す

**Unity FBX 書き出し** 欄の **FBX Exporter For Unity** を押すと、アニメーション付きの FBX を書き出す画面が開きます。書き出しはシーンのコピーに対して別のプロセスで行うので、作業中のシーンは変更されません。

1. ジオメトリと、スキンのジョイントをすべて含む親グループを選択します。
2. **Use selection** で対象を指定し、開始・終了フレームを確認します。
3. **Export and verify on a copy** を押し、新しい FBX ファイル名を指定します。既存のファイルは上書きされません。

書き出した FBX は、もう一度読み込んでメッシュ・頂点数・表情の名前・変形が元のシーンと一致するかを確認します。確認で問題が見つかった場合は FBX を出力せず、原因を記録します。

書き出しを始めると「書き出し状況」の画面が開き、複数の書き出しを同時に進められます。完了や失敗は一覧に残り、**書き出し状況を表示** ボタンでいつでも開き直せます。一覧の行を選ぶと、出力先や失敗の理由を確認できます。

書き出しの作業フォルダーは OS の一時フォルダーに作られ、ログと復元用のシーンが残ります。不要になったら削除してください。

次のような場合は、推測で変換せずにエラーにします。

- スキンが複数ある
- FBX で保持できない大きさのシアーがある
- `offsetParentMatrix` を使った階層など、対応していない構成がある

### Unity で読み込む

書き出した FBX を、そのキャラクターのアニメーションとして再生する場合は、Unity の Import Settings で次のように設定します。

- **Rig** の **Animation Type** を `Generic` にする
- **Import BlendShapes** をオンにする

`unity/Editor/AutoRigFbxImport.cs` を Unity プロジェクトの `Editor` フォルダーに入れると、FBX を選んで **Assets > AutoRig > Use Source Animation (Generic)** から、この設定をまとめて適用できます。別のキャラクターへ Humanoid としてリターゲットする使い方は、動作を確認していません。

### FBX 内のブレンドシェイプ名を変換する

**FBXの変換** 欄では、FBX 内のブレンドシェイプ名（日本語名など）を別の名前に置き換えた FBX を作れます。Maya のシーンは変更しません。

1. **変換元 FBX** の **参照** でファイルを選びます。Json と変換後 FBX のパスは自動で入力されます。
2. **Json出力** を押すと、元の名前と変換後の名前の対応表が作られます。
3. 対応表を開き、変換後の名前を編集します。変換後の名前が重複するとエラーになります。
4. **モード** を選んで **FBX出力** を押します。
   - `Kay To Value`: 元の名前を変換後の名前に置き換えます。
   - `Value To Kay`: 変換後の名前を元の名前に戻します。

## 制限事項

- 一般的な人型のキャラクターにだけ対応しています。四足歩行や腕が3本以上あるキャラクターには使えません。
- すでにリグがあるシーンでは、新しくリグを作れません。別のシーンで作ってから、[別ファイルのリグを読み込む](#別ファイルのリグを読み込む) で読み込んでください。
