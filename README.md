# AutoRigForHumanoid For Maya

ヒューマノイドキャラクターのジョイントを指定するだけで、FK/IK 切り替え付きのコントローラーリグを自動で作る Maya 用ツールです。
リグ作成のほかに、ポーズを付けるための Picker、ブレンドシェイプ用コントローラー、FBX の入出力などをひとつのウィンドウから使えます。

## できること

- **リグの自動作成** — 体幹・頭・腕・脚・指のコントローラーを一括で作成
- **FK/IK の切り替え** — 腕と脚を FK でも IK でも操作でき、切り替えてもポーズが飛びません
- **Picker** — ボタンでコントローラーを選択、ポーズのリセット、左右ミラーなどをワンクリックで実行
- **ブレンドシェイプ用コントローラー** — 表情などを、枠の中で動かすコントローラーで操作
- **リグの作り直しに対応** — コントローラーの形を保存して、作り直したリグへ復元
- **別ファイルのリグの読み込み** — 別の Maya ファイルのリグを、Picker が使える状態でシーンへ読み込み
- **FBX の入出力** — FBX の読み込み、Unity 向けの書き出し、ブレンドシェイプ名の変換

## 動作環境

- Autodesk Maya 2025 以降
- Windows

## インストールと起動

1. このページの **Code > Download ZIP** でダウンロードして展開し、フォルダ名を `AutoRigForHumanoid` にして、次の場所へ置きます。

   ```
   C:\Users\<ユーザー名>\Documents\maya\scripts\AutoRigForHumanoid
   ```

2. Maya のスクリプトエディター(Python タブ)で次を実行すると、ウィンドウが開きます。

   ```python
   from AutoRigForHumanoid import show_window
   show_window()
   ```

   毎回打つのが面倒なときは、上のコードを選択してシェルフへドラッグすると、ボタンとして登録できます(アイコンには同梱の `ARFH_icon.png` を使えます)。

## リグの作り方

スキン済みのヒューマノイドキャラクターをシーンに開いた状態で、ウィンドウの **リグ制作** タブを使います。

### 1. 関節を割り当てる(初期設定)

1. **キャラクター名** を入力します。
2. Hips・Spine・腕・脚・頭・目など、各欄にキャラクターのジョイントを入れます。
   - **自動割り当て**: ジョイント名から推測してまとめて入力します。まずこれを押すのがおすすめです。
   - **割り当て**: シーンで選んだジョイントをその欄に入れます。
   - **選択**: 欄のジョイントをシーンで選択して確認します。
3. 指(Left Hand / Right Hand)は最初は折りたたまれています。指が無いキャラクターは空のままで構いません。

### 2. ガイドを作る

1. **主軸**(ジョイントの向きの基準にする軸)を選びます。
2. **ガイド作成** を押します。
3. 作られたガイドを動かして、手足や体幹の位置・向きを調整します。向きがずれているときは **90°回転** の X / Y / Z ボタンで直せます。

### 3. リグを作る

**リグ作成** を押すと、コントローラー一式が作られます。うまくいかなかったときは Ctrl+Z で作成前に戻せます。

### 4. ポーズを付ける

ウィンドウ上部の **Picker表示** で Picker を開きます。

| ボタン | できること |
|---|---|
| 図の各ボタン | そのコントローラーを選択(Shift を押しながらで追加選択) |
| All Finger | 指のコントローラーをまとめて選択 |
| Select ALL | すべてのコントローラーを選択 |
| Reset Pose | すべてのコントローラーを初期状態に戻す |
| Mirror Pose | 現在のポーズを左右反転 |
| IK>>FK / FK>>IK | 腕・脚の FK/IK を、見た目のポーズを保ったまま切り替え(左右別) |
| ArmVis / LegVis / HandVis など | 部位ごとにコントローラーの表示・非表示を切り替え |
| Flat Shade | ビューポートをフラット表示にする |

- 腕と脚は、作成直後の状態では **腕が FK、脚が IK** です。
- ホイールで Picker の表示を拡大・縮小できます。
- 1 つのシーンに複数のキャラクターがいる場合の切り替え方法は、下の「複数のキャラクターを 1 つのシーンで使う」を見てください。

### リグを作り直したいとき

コントローラーの形を手直ししたあとでリグを作り直したいときは、**リグ制作** タブの **コントロールシェイプ** を使います。

1. 作り直す前に **Export Shape** で形を保存します。
2. リグを作り直します。
3. **Import Shape** で保存した形を読み込むと、同じ名前のコントローラーに形が戻ります。

コントローラーを選択しているときは、選択したものだけが対象です。何も選択していなければすべてが対象になります。

## ブレンドシェイプ用コントローラー

**ブレンドシェイプ** タブで、表情などのブレンドシェイプを操作するコントローラーを作れます。

1. **オブジェクト** に顔などのメッシュを割り当て、**シェイプ**・**スキンクラスター**・**ブレンドシェイプ** を「自動割り当て」で入力します。
2. **適用** を押します。
3. 作りたいコントローラーの種類を開き、名前・色・対応するブレンドシェイプを選んで **作成** を押します。

| 種類 | 動かし方 |
|---|---|
| 1*1 | 1 方向に動かして 1 つのブレンドシェイプを操作 |
| 2*1 | 1 方向に動かして、プラス側・マイナス側の 2 つを操作 |
| 1*2 | 縦横 2 方向に動かして、それぞれ 1 つずつ操作 |
| 2*2 | 縦横 2 方向に動かして、それぞれプラス・マイナスの計 4 つを操作 |

## アクセサリ

**アクセサリ** タブには、補助的な機能がまとまっています。

### リグ読み込み

別の Maya ファイルで作ったリグを、いまのシーンへ読み込みます。読み込んだリグも、そのまま Picker で操作できます。

1. **Maya Scene** に読み込みたいファイルを指定します(**参照** で選べます)。
2. **Import Rig** を押します。

- このツールで作ったリグを読み込むためのものです。
- 古い版で作ったリグは、読み込めても Picker が使えないことがあります。その場合はリグを作り直してください。

### 複数のキャラクターを 1 つのシーンで使う

別ファイルのリグを読み込むと、1 つのシーンに複数のキャラクターを置けます。Picker で操作する対象は、`ARFH_information` ノードの `characterName` にキャラクター名を入力して切り替えます。

### FBX

**FBX** サブタブには 3 つの機能があります。

**FBXインポート**
- **Import FBX**: FBX ファイルをシーンへ読み込みます。
- **Freeze Scale**: 読み込んだキャラクターのスケールが 1 でなく、メッシュが痩せたり崩れたりするときに、ジョイントのルートを選んで押すと直ります。

**Unity FBX 書き出し**
**FBX Exporter For Unity** を押すと、アニメーション付き FBX を Unity 向けに書き出す画面が開きます。作業中のシーンには手を加えずに、確認付きで書き出します。詳しい使い方は [UNITY_FBX_EXPORT.md](UNITY_FBX_EXPORT.md) を見てください。

**FBX名の整形**
FBX の中のブレンドシェイプ名(日本語名など)を別の名前に置き換えた FBX を作ります。Maya のシーンは変わりません。

1. **変換元 FBX** の **参照** でファイルを選びます(Json と変換後 FBX のパスは自動で入ります)。
2. **Json出力** を押すと、元の名前と変換後の名前の対応表ができます。
3. 対応表を開いて、変換後の名前を必要に応じて編集します(変換後の名前が重複するとエラーになります)。
4. **モード** を選んで **FBX出力** を押します。
   - `Kay To Value`: 元の名前 → 変換後の名前
   - `Value To Kay`: 変換後の名前 → 元の名前(元に戻す)

## ウィンドウの見方

ウィンドウ上部に **Picker** ボタンが常に表示され、その下がタブになっています。

| 場所 | 内容 |
|---|---|
| Picker(常時表示) | ポーズ操作用の Picker を開く |
| リグ制作 | 初期設定 → ガイド作成 → リグ作成 → コントロールシェイプ |
| アクセサリ | リグ読み込み、FBX(インポート・Unity 書き出し・名前の整形) |
| ブレンドシェイプ | ブレンドシェイプ用コントローラーの作成 |

## 制限事項

- 二足歩行のヒューマノイド専用です。四足などのキャラクターには使えません。
- 腕や脚がほぼまっすぐな状態(T ポーズなど)でも作れます。その場合、脚は前側、腕は後ろ側に曲がるようになります。
- 同じ名前のリグが既にあるシーンでは、そのキャラクター名ではリグを作れません。別の名前にするか、既存のリグを削除してください。
- Unity 向けの FBX 書き出しの確認は、一部のフレームのサンプルで行っています。全フレーム・全頂点を確認するものではありません。
